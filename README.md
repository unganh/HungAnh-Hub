# Hung Anh Hub

Trang chủ tổng hợp các dự án, công cụ và sản phẩm của Hùng Anh trên GitHub.

## Chạy website

Website là trang tĩnh, không cần cài đặt framework. Mở `index.html` trên trình duyệt để xem.

## Bật GitHub Pages

1. Mở tab **Settings** của repository này.
2. Chọn **Pages** ở menu bên trái.
3. Trong **Build and deployment**, chọn **Deploy from a branch**.
4. Chọn branch **main**, folder **/(root)**, rồi bấm **Save**.
5. Đợi GitHub hoàn tất triển khai. Đường dẫn website dự kiến: https://unganh.github.io/HungAnh-Hub/

## Tự động cập nhật danh sách dự án

Trang chủ đọc các repository công khai, không phải fork, từ GitHub API của tài khoản `unganh`. Khi tạo repository công khai mới, danh sách dự án sẽ tự cập nhật khi người xem mở hoặc tải lại trang; không cần sửa danh sách thủ công. Repository HungAnh-Hub được loại khỏi danh sách.

## Thêm sự kiện hoặc bộ sưu tập mới

Phần **Sự kiện & bộ sưu tập** hiện là nội dung giới thiệu mẫu. Khi có sự kiện cụ thể, cập nhật các thẻ trong phần `<section id="events">` của `index.html`, thêm tên, mô tả, thời gian và liên kết tới trang/repository tương ứng.
